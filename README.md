# LASERTAG Configurator для macOS

**Русский** | [English](README.en.md)

Неофициальный конфигуратор устройств LaserWar для Mac — на Apple Silicon (M1–M4) и Intel.

- **Устройства** настраиваются через «Умный пульт Про» (USB): умная контрольная точка 2.0, умная аптечка 2.0,
  умный медик, командный пункт и устройства с пометкой «(тест)» — универсальная точка, бомба, система «Купол»,
  универсальный пульт, артефакт, заложник, зомби, бронежилет / шлем, гранатомёт.
- **Статистика игры (тест)** — чтение бластеров 7, 8 и 9 поколений по Bluetooth, рейтинг, звания, команды,
  файлы игры `.xml` (совместимы с Windows-конфигуратором) и отчёт PDF.
- Пресеты настроек, журнал обмена для диагностики, интерфейс на русском и английском.

## Требования

| | |
|---|---|
| macOS | **12 Monterey или новее** (13 Ventura, 14 Sonoma, 15 Sequoia, 26 Tahoe) |
| Процессор | Apple Silicon (M1, M2, M3, M4) или Intel |
| Устройства | «Умный пульт Про» и кабель USB; драйвер не нужен |
| Статистика | Bluetooth на Mac и сопряжённые бластеры 7–9 поколений |

Устанавливать .NET или другие программы не нужно — всё уже внутри приложения.

## Скачать

Откройте страницу **[Releases](../../releases/latest)** и скачайте архив под свой Mac:

| Ваш Mac | Файл |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `LaserTag-mac-arm64.tar.gz` |
| Intel | `LaserTag-mac-x64.tar.gz` |

Не знаете, какой у вас процессор? Меню Apple → «Об этом Mac»: строка «Чип» (Apple M…) — Apple Silicon,
строка «Процессор» (Intel …) — Intel.

## Установка

### Способ 1. Вручную

1. Дважды щёлкните по скачанному архиву — рядом появится `LaserTag.app`.
2. Перетащите `LaserTag.app` в папку **«Программы»**.
3. Приложение не подписано сертификатом Apple, поэтому macOS при первом запуске его блокирует.
   Откройте **Терминал** (Программы → Утилиты) и выполните:

   ```bash
   xattr -cr /Applications/LaserTag.app
   ```

4. Запустите LaserTag из «Программ» или Launchpad.

Если macOS всё равно пишет, что приложение «повреждено» или «не может быть открыто»:

```bash
codesign --force --deep -s - /Applications/LaserTag.app
```

Можно и без Терминала: щёлкните по приложению правой кнопкой → **«Открыть»** → **«Открыть»**.
На macOS 15 Sequoia и новее: попробуйте открыть приложение, затем зайдите в
**Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.

### Способ 2. Скриптом

Скачайте со страницы Releases также `install-mac.sh` и положите его рядом с архивом (обычно в «Загрузки»).
В Терминале:

```bash
cd ~/Downloads
bash install-mac.sh
```

Скрипт сам выберет архив под ваш процессор, установит приложение в «Программы», снимет блокировку и запустит его.
Если Safari уже распаковал архив сам (в «Загрузках» лежит `LaserTag.app` вместо `.tar.gz`), воспользуйтесь способом 1.

### Ошибка −36 («не удалось завершить операцию»)

Так бывает, если архив лежит в сетевой папке или в общей папке виртуальной машины.
Сначала скопируйте архив на диск Mac (например, в «Загрузки»), затем распакуйте и установите оттуда.

### Обновление и удаление

- Обновление: скачайте новый архив и замените `LaserTag.app` в «Программах» (затем снова `xattr -cr …`).
- Удаление: перетащите `LaserTag.app` в Корзину. Настройки лежат в `~/Library/Application Support/LaserTag`,
  пресеты и статистика — в `~/Documents/LASERTAG`.

## Первые шаги

### Настройка устройств через пульт

1. Подключите «Умный пульт Про» кабелем USB и включите его.
2. Нажмите **Подключить пульт** внизу окна — порт и протокол определяются автоматически.
3. Выберите устройство слева, направьте пульт на его ИК-приёмник (1–2 м).
4. **Проверить связь** → **Чтение** (если устройство его поддерживает) → измените поля → **Запись**.

### Статистика по Bluetooth

1. Включите бластер. **Системные настройки → Bluetooth** → выберите `LW_RIFLE`, `LW_RIFLE_V8`
   или `BIATHLON_V8` → PIN-код **1234**.
2. В программе: **Игра → Статистика**, нажмите **Обновить**. При первом обращении macOS спросит доступ
   к Bluetooth — нажмите **«Разрешить»** (или включите LaserTag в «Конфиденциальность и безопасность → Bluetooth»).
3. Отметьте бластеры и нажмите **Считать выбранные**. Бластеры с одинаковыми именами различаются по концу
   адреса, после первого чтения рядом появляется ID игрока.
4. **Отчёт PDF…** формирует отчёт для печати.

## Ограничения

- Устройства и разделы с пометкой **«(тест)»** перенесены с Windows-версии, но ещё не проверены на всём
  оборудовании. После записи проверьте результат на устройстве; цифры статистики сверьте с Windows-конфигуратором.
- Программа неофициальная, без подписи Apple.
